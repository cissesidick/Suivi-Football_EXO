##  Pourquoi ce projet ?

J'ai choisi le **Suivi de Football**  parce que c'est un sujet que je connais et qui me motive.
Un match, un entraînement ou une saison produisent beaucoup d'informations :
des dates, des scores, des points forts, des points faibles. C'est un bon terrain pour apprendre à organiser des notes et à les relier entre elles.
J'ai voulu construire le coffre **moi-même, de A à Z**, pour comprendre comment
fonctionne Obsidian plutôt que de partir d'un modèle tout fait.

##  Pourquoi j'ai fait ce découpage ?

J'ai découpé le coffre comme on suit réellement la progression d'un joueur :

- **Match/** → c'est là que je vois mes résultats. Une note par match permet
  de comparer mes performances dans le temps.
- **entrainement/** → les matchs montrent le résultat, les entraînements montrent
  le travail fait pour y arriver.
- **competence/** → je découpe le jeu en compétences précises (coups francs,
  défense, hors-jeu, penaltys) pour savoir exactement quoi travailler.
- **objectif/** → fixer des objectifs pour la saison donne une direction
  à tout le reste.
- **Saison-abidjan/** → regroupe toute une saison au même endroit pour en
  avoir une vue globale.
- **Tableau de bord** → je ne veux pas ouvrir chaque dossier : une seule page
  me montre tout d'un coup d'œil.

L'idée générale ici était de montrer :  **objectif → compétences à travailler → entraînements → matchs**.
Chaque dossier correspond à une étape de la progression.

##  Pourquoi j'ai choisi les plugin suivants : 

- **Excalidraw** : j'ai commencé par dessiner l'organisation du coffre
  avant de le construire, pour réfléchir à la structure d'abord.
- **Dataview** : j'ai utilisé dataview pour pouvoir remplir le tableau de bord automatiquement sans pour que moi même je viens les faire à la main
- **Templater** : toutes mes notes de match ont la même structure, ce qui les rend faciles à comparer et rapides à créer.
- **Calendar** : l'objectif était de voir les matchs joués grâce au calendrier et de voir aussi les matchs a venir pour la suite
